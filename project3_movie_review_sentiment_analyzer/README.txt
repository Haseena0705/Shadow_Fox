# Movie Review Sentiment Analyzer

A Python project that classifies movie reviews as **Positive** or **Negative** using a pre-trained DistilBERT model from Hugging Face.

## Features

- Fine-tunes DistilBERT on sample movie reviews.
- Evaluates model accuracy on a validation set.
- Predicts sentiment for new movie reviews.

1. Clone this repository or download the files.
2. Install dependencies:
